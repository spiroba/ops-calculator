# 📊 ИНСТРУКЦИЯ ПО КАЛЬКУЛЯТОРУ ПРЕМИЙ ОПС

## 🎯 ОБЩЕЕ ОПИСАНИЕ

Калькулятор премий ОПС - автоматизированный инструмент для расчета персональных премий сотрудников отделений почтовой связи согласно **Приложению № 1 к распоряжению АО "Почта России"**.

### Основные принципы расчета:
- **Личный бонус** = премия за выполненные операции × командные коэффициенты
- **КПИ премия** = коэффициент выполнения КПИ × базовая сумма
- **Командный бонус** = 3% от премий подчиненных (только для руководителей)
- **Итоговая премия** = (личный бонус + КПИ + командный бонус) × коэффициент эффективности ОПС

## 👥 ОПИСАНИЕ ДОЛЖНОСТЕЙ

### 1. 🔧 **ОПЕРАТОР 1-3 КЛАССА**
**Характеристика:** Основной исполнитель операций в ОПС
- **Операции:** 16 видов (№1, 3-7, 15-24)
- **КПИ:** ❌ НЕТ
- **Коэффициенты:** Сервис + Скорость + Эффективность
- **Особенности:** НЕ выполняет доставку гиперлока, платежи МПКТ, ПВЗ WB, привлечение клиентов

### 2. 🏢 **НОПС БЕЗ ОПЕРАТОРОВ (оперативный)**
**Характеристика:** Начальник, который сам выполняет операции
- **Операции:** 15 видов (№1, 3-7, 15-20, 23-25)
- **КПИ:** ❌ НЕТ
- **Коэффициенты:** Сервис + Скорость приема + Скорость вручения + Эффективность
- **Особенности:** НЕ выполняет вручение, доставку, МПКТ, розницу 16ДП

### 3. 👨‍💼 **НОПС С ОПЕРАТОРАМИ (управленческий)**
**Характеристика:** Начальник, который НЕ выполняет операции лично
- **Операции:** ❌ НЕТ (только управленческие функции)
- **КПИ:** ✅ Все 4 (выручка, CSI, онлайн-РПО, CO1/CO2)
- **Коэффициенты:** Только эффективность
- **Командный бонус:** +3% от премий всех подчиненных

### 4. 💻 **АДМИНИСТРАТОР**
**Характеристика:** Специалист с ограниченным функционалом
- **Операции:** 2 вида (№3 лото, №16 EMS предоплаченные)
- **КПИ:** ✅ Частично (выручка, CSI, онлайн-РПО)
- **Коэффициенты:** Сервис + Скорость + Эффективность
- **Особенности:** НЕТ КПИ по своевременности (CO1/CO2)

### 5. 🚶‍♂️ **ПОЧТАЛЬОН**
**Характеристика:** Работник выездного обслуживания
- **Операции:** 8 видов (№2-9, только тип 2)
- **КПИ:** ❌ НЕТ
- **Коэффициенты:** Сервис + Эффективность (НЕТ скорости)
- **Особенности:** Специализируется на доставке и выездных операциях

### 6. 🎖️ **ГЛАВНЫЙ СПЕЦИАЛИСТ**
**Характеристика:** Универсальный специалист с максимальными правами
- **Операции:** ✅ ВСЕ 25 операций
- **КПИ:** ❌ НЕТ
- **Коэффициенты:** Сервис + Скорость + Эффективность
- **Особенности:** Единственный, кто может выполнять ВСЕ операции

## 📊 СИСТЕМА КПИ

### 💰 **КПИ ВЫРУЧКА ОПС** (критический показатель)
| Выполнение плана | Коэффициент | Примечание |
|------------------|-------------|------------|
| < 80% | 0 | ⚠️ ВСЕ КПИ = 0 |
| 80% - 89% | 0.3 | |
| 90% - 99% | 0.5 | |
| 100% - 149% | Факт % / 100 | |
| ≥ 150% | 1.5 | Максимум |

### 🌟 **ОСТАЛЬНЫЕ КПИ**
| КПИ | Выполнение < 100% | Выполнение = 100% | Выполнение > 100% |
|-----|-------------------|-------------------|-------------------|
| CSI канала "Сеть" | 0 | 1.0 | До 1.2 |
| Доля онлайн-РПО | 0 | 1.0 | До 1.2 |
| CO1/CO2 (своевременность) | 0 | 1.0 | До 1.2 |

**Базовая сумма КПИ:** 5 000₽ за каждый показатель

## 🔥 КРИТИЧЕСКИЕ ПРАВИЛА

### ⚠️ **ПРАВИЛО 80% ВЫРУЧКИ**
- При выполнении плана по выручке < 80% → **ВСЕ КПИ = 0**
- Операции продолжают начисляться с коэффициентами
- Командный бонус НЕ затрагивается

### 👨‍💼 **КОМАНДНЫЙ БОНУС (только для руководителей)**
- **НОПС с операторами:** 3% от суммы премий всех подчиненных
- Вводится общая сумма премий подчиненных
- Применяется коэффициент эффективности

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ ИСПОЛЬЗОВАНИЯ

### ШАГ 1: Выбор должности
1. Выберите соответствующую должность из 6 доступных
2. Интерфейс автоматически покажет доступные операции и поля

### ШАГ 2: Заполнение операций
1. Введите количество/суммы по выполненным операциям
2. Используйте правильные единицы измерения (₽, шт, чел, заказ)
3. Для процентных операций вводите сумму в рублях

### ШАГ 3: Заполнение КПИ (если есть)
1. Введите процент выполнения каждого КПИ
2. Обязательно заполните КПИ Выручка (критический)
3. CSI вводите в процентах выполнения плана

### ШАГ 4: Командные коэффициенты
1. **CSI:** вводите в баллах (0-100)
2. **Скорость:** процент выполнения временных нормативов
3. **Эффективность:** процент выполнения плана по выручке

### ШАГ 5: Дополнительные поля
- **Для НОПС с операторами:** введите общую сумму премий подчиненных

### ШАГ 6: Получение результата
1. Нажмите "Рассчитать премию"
2. Проверьте детализацию по каждому виду премии
3. Итоговая сумма учитывает все коэффициенты и ограничения

## ❗ ВАЖНЫЕ ПРИМЕЧАНИЯ

### 🚨 **ЧАСТЫЕ ОШИБКИ**
1. **CSI путаница:** В КПИ вводите %, в коэффициентах - баллы
2. **Правило 80%:** Действует только на КПИ, не на операции
3. **Типы операций:** Коэффициенты применяются автоматически по типу
4. **НОПС роли:** Управленческий НЕ выполняет операции лично

### 💡 **СОВЕТЫ ПО ИСПОЛЬЗОВАНИЮ**
- Всегда заполняйте КПИ Выручка первым (критический показатель)
- При CSI < 90 баллов снижается премия за операции типа 2
- Коэффициент эффективности влияет на ВСЮ итоговую премию
- Командный бонус для НОПС считается автоматически

### 📞 **ТЕХНИЧЕСКАЯ ПОДДЕРЖКА**
При обнаружении ошибок в расчетах или несоответствий документу обращайтесь к разработчику с указанием:
- Выбранной должности
- Введенных данных
- Ожидаемого и фактического результата
